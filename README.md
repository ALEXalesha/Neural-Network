# Neural Network Lab

Сборник учебных и прикладных проектов по машинному обучению и нейросетям на
**Python / PyTorch**: от классификации рукописных цифр до собственной языковой
модели (AlexGPT), переводчика, генеративных сетей и набора десктоп/веб-приложений.

> В репозиторий залит **только исходный код** (Python, HTML, JS, конфиги, bat-скрипты).
> Веса моделей (`*.pth`), датасеты (`*.tsv`, `*.txt`), картинки и собранные `*.exe`
> исключены через `.gitignore` — их нужно сгенерировать обучающими скриптами или
> скачать (`download_models.py`, `download_text.py`).

---

## Структура проекта

### Языковые модели (GPT / NLP)
| Файл | Назначение |
|------|------------|
| `mini_gpt.py` | Минимальная GPT-архитектура (трансформер) с нуля |
| `gpt_bpe.py` | GPT с BPE-токенизацией |
| `train_multilingual.py` | Обучение многоязычной (RU/EN) языковой модели |
| `text_gen.py`, `text_gen_big.py` | Генерация текста обученной моделью |
| `lm_config.json` | Конфигурация языковой модели (слои, размерности, гиперпараметры) |

### Перевод
| Файл | Назначение |
|------|------------|
| `translator.py` | Нейросетевой переводчик (seq2seq) |
| `train_translator_bpe.py` | Обучение переводчика с BPE-токенизацией |

### Компьютерное зрение
| Файл | Назначение |
|------|------------|
| `mnist.py`, `mnist_cnn.py`, `mnist_cnn_v2.py`, `mnist_cnn_v3.py` | Классификация цифр MNIST (полносвязная и CNN-версии) |
| `mnist_draw.py` | Рисование цифры мышью и распознавание в реальном времени |
| `retrain_mnist_web.py` | Дообучение MNIST-модели для веб-версии |
| `vision.py` | Базовые операции компьютерного зрения |
| `image_processing.py` | Обработка изображений |
| `gan.py` | Генеративно-состязательная сеть (GAN) для генерации изображений |
| `tta.py` | Test-Time Augmentation |

### Прикладные ML-задачи
| Файл | Назначение |
|------|------------|
| `anomaly.py` | Поиск аномалий |
| `clustering.py` | Кластеризация |
| `regression.py` | Регрессия |
| `sentiment.py` | Анализ тональности текста |
| `train_spam.py` | Классификатор спама |
| `train_ner.py` | Распознавание именованных сущностей (NER) |
| `train_recommender.py` | Рекомендательная система |
| `train_defect.py` | Детекция дефектов |
| `temperature.py`, `train_temperature.py` | Прогноз температуры |
| `timeseries.py` | Анализ и прогноз временных рядов |
| `math_solver.py` | Решение математических задач |
| `neural_network.py` | Базовая реализация нейросети «с нуля» |

### Ассистенты и «команда кодеров»
| Файл | Назначение |
|------|------------|
| `assistant.py`, `smart_assistant.py` | Десктопный умный ассистент |
| `smart_web.py`, `web_app.py`, `app_server.py` | Веб-версии ассистента (сервер + UI) |
| `desktop_app.py` | Десктопное приложение (Qt/WebChannel) |
| `coder_team.py`, `coder_team_v2.py` | «Команда» ИИ-агентов для генерации кода |
| `coder_output.py`, `coder_output_v2.py` | Вывод/исполнение результатов команды кодеров |

### Интерфейс и запуск
| Файл | Назначение |
|------|------------|
| `menu.py` | Главное меню для запуска модулей |
| `_launch_*.py`, `launcher_*.py` | Лаунчеры отдельных приложений |
| `templates/`, `static/` | HTML-шаблоны и статика для веб-приложений |
| `start_*.bat`, `build_all.bat` | Bat-скрипты запуска и сборки (PyInstaller) |

### Утилиты
| Файл | Назначение |
|------|------------|
| `download_models.py` | Загрузка предобученных весов моделей |
| `download_text.py` | Загрузка текстовых корпусов для обучения |

---

## Запуск

```bash
# Установка зависимостей
pip install torch torchvision flask numpy pillow

# Главное меню
python menu.py

# Или конкретный модуль, например распознавание нарисованных цифр
python mnist_draw.py

# Веб-ассистент
python web_app.py   # затем открыть http://localhost:5000
```

## Требования
- Python 3.10+
- PyTorch (CPU или CUDA)
- Дополнительно: Flask, NumPy, Pillow (для веб- и графических модулей)
