Учебный проект по нейросетям на PyTorch. Внутри два слоя:

- `alexgpt/` - десктоп-приложение AlexGPT: 16 своих нейросетей (перевод, тональность, спам, имена и даты в тексте, угадывание рисунков, цифры, прогнозы и т.д.) плюс чат, решатель тестов и "Команда кодеров" через LM Studio.
- `lab/` - скрипты, на которых эти модели обучены, и учебные эксперименты.

## Скачать

Готовые сборки лежат в [релизах](https://github.com/ALEXalesha/Neural-Network/releases/latest):

- `AlexGPT-<версия>-setup.exe` (433 МБ) - установщик. Ставится без прав администратора в `%LOCALAPPDATA%\Programs\AlexGPT`, создаёт ярлыки.
- `AlexGPT-<версия>-portable.zip` (540 МБ) - распаковать куда угодно и запустить `AlexGPT.exe`. Настройки и чаты хранятся в папке `data` рядом с exe.

Python на компьютере не нужен. Свои нейросети работают на CPU без интернета, видеокарта не обязательна.

### Угадай рисунок: несколько символов

Сеть обучена на одиночных символах, и раньше весь холст шёл в неё одним кадром 28×28: «65» превращалось в «W». С версии 1.3 сервер сам режет рисунок на символы (`alexgpt/sketch_segment.py`):

1. Ищет связные пятна краски (на копии не больше 128×128 - быстро и без разрывов в тонких линиях); пятна меньше 1% всей краски считаются сором.
2. Пятна, перекрывающиеся по горизонтали хотя бы на 30% более узкого, - один символ: «=», «i», «÷» и «5» с отдельной чертой остаются целыми. Остальные - разные символы, слева направо.
3. Каждый символ отдельно идёт в ту же сеть, строка читается по правилам:
   - **число** - если хотя бы половина символов цифры (или «|» и «°»: так сеть зовёт палочку и круглый ноль), похожие знаки становятся цифрами (| l I → 1, ° O o → 0, S → 5, b → 6 …), спорный символ - лучшей цифрой, если у неё хотя бы 10%;
   - **надпись** - картинка вроде «рыба» внутри строки из знаков меняется на лучший знак (от 10%);
   - **слово** - если хотя бы половина символов латинские буквы, спорный символ становится лучшей буквой (от 10%);
   - **регистр** - c, o, s, u, v, w, x, z строчная и заглавная рисуются одинаково, и нормализация размер стирает. В строке он виден: ниже 3/4 роста высоких символов (цифры, заглавные, b d f h k l t) - строчная.

Один символ или картинка («кошка») - ответ прежний. Если символов 2-12, API дополнительно возвращает `text`, `confidence` и `symbols` (каждый с лучшей альтернативой), страница показывает строку крупно и разбивку по символам. Слитное письмо одним мазком так не разрезать - для этого нужна модель, читающая строку целиком, и её пришлось бы обучать заново.

## Модуль рисования

PyTorch для видеокарты и diffusers весят около 5 ГБ, поэтому в установщик они не входят. В разделе "Нарисовать по описанию" есть кнопка "Установить модуль рисования": программа сама скачает [uv](https://github.com/astral-sh/uv), поставит через него отдельный Python 3.12, PyTorch (CUDA, если есть видеокарта NVIDIA, иначе версию для процессора), diffusers и модель SDXL-Turbo (6,5 ГБ, общий кэш Hugging Face - если модель уже скачана, второй раз не качается). Прогресс виден в окне.

Всё ставится в папку данных (`addons\draw`), рисует отдельный процесс `draw_worker.py`, который держит модель в памяти между картинками и закрывается вместе с программой. Кнопки "Удалить модуль" и "Удалить модуль и модель" освобождают место. При запуске из исходников модуль не нужен, если в `.venv` уже есть diffusers.

## LM Studio

1. Установи [LM Studio](https://lmstudio.ai) и включи в нём Local Server (порт 1234). Если есть CLI `lms`, приложение управляет моделями само.
2. В AlexGPT открой "Модели: скачать и удалить". Там четыре роли с понятными названиями и размерами:

| Роль | Модель | Размер | Зачем |
|------|--------|--------|-------|
| Кодер | DeepSeek Coder 6.7B | 3,9 ГБ | Пишет и чинит код |
| Аналитик | DeepSeek R1 Distill Qwen 7B | 4,7 ГБ | Рассуждает, решает задачи и тесты по тексту |
| Писатель | Qwen2.5 7B Instruct | 4,7 ГБ | Обычный чат, ревью кода |
| Зрение | Qwen2-VL 7B | 7,4 ГБ | Фото и скриншоты заданий |

Кнопка "Скачать" запускает `lms get` и показывает прогресс, "Удалить" стирает файлы модели с диска (только внутри папки моделей LM Studio). Можно скачать любую другую модель по ссылке `https://huggingface.co/<автор>/<репозиторий>@<квантизация>`. Для 8 ГБ видеопамяти подходят модели до 7-8B в квантизации Q4_K_M.

Модели грузятся в память сами при первом запросе, поэтому первый ответ может занять до минуты. Аналитик (R1) сначала думает: ход его мыслей виден в чате в свёрнутом блоке "💭 Размышления".

## Запуск из исходников

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements-dev.txt
.venv\Scripts\python alexgpt\main.py
```

Веса моделей лежат в `models/` через Git LFS (207 МБ), поэтому перед клонированием нужен `git lfs install`. Бесплатный трафик LFS на GitHub - 1 ГБ в месяц на весь репозиторий: если после клонирования вместо `.pth` лежат маленькие текстовые файлы, квота кончилась, и те же веса есть внутри portable-сборки в релизах.

Свой `lm_config.json` положи в папку данных, чтобы он не терялся при обновлениях: `.appdata/` при запуске из исходников, `%LOCALAPPDATA%\AlexGPT` в установленной версии, `data/` в portable.

## Тесты

```bash
.venv\Scripts\python -m pytest tests
```

271 тест, около 40 секунд. Большая часть проверяет инварианты на сотнях случайных входов (hypothesis): сервер никогда не падает с 500, JSON валиден, вероятности суммируются в 100%, удаление моделей не выходит за папку LM Studio, разбор ответов модели не ломается на любом тексте. Отдельно `test_model_quality.py` проверяет, что обученные модели отвечают правильно на очевидных примерах (так ловится сломанный переводчик), а `test_lm_chat.py` - логику чата и "Решить тест" на поддельном LM Studio. `test_sketch_segment.py` проверяет разрезание (каждая капля краски ровно в одном символе, символы слева направо, тонкая диагональ не рассыпается, сор не становится символом) и правила чтения на тысячах случайных вероятностей, а на настоящей модели - что нарисованные «10», «11», «70», «101», «ABC», «bc» читаются ровно так; мутационная проверка модуля - 29 поломок из 29 ловятся. Для 1000 примеров на тест: `HYPOTHESIS_PROFILE=thorough`.

## Сборка exe, portable и установщика

```bash
powershell -ExecutionPolicy Bypass -File packaging\build.ps1
```

Скрипт сам создаст `packaging/.buildvenv` с torch CPU, соберёт PyInstaller-версию и положит в `packaging/dist/` portable-zip и установщик (нужен NSIS: `winget install NSIS.NSIS`).

## Лаборатория

Скрипты запускаются из папки `lab` (`cd lab`), зависимости в `lab/requirements.txt`. Датасеты скачиваются с Hugging Face сами, результаты (`*.pth`) остаются локально. Чтобы приложение взяло новую модель, скопируй `.pth` в `models/`.

| Скрипт | Модель | Время на RTX-видеокарте |
|--------|--------|------|
| `train_translator_bpe.py` | Переводчик EN↔RU (нужны `tatoeba_*.tsv.bz2` с tatoeba.org) | ~2 ч на направление |
| `train_sentiment.py` | Тональность, RuReviews | 2 мин |
| `train_spam.py` | Спам, SMS Spam Collection + русский перевод | 1 мин |
| `train_ner.py` | NER, WikiANN + шаблоны с датами | 25 мин |
| `retrain_mnist_web.py` | Цифры для рисования | |
| `train_*.py` остальные | Аномалии, брак, кластеры, рекомендации, температура | минуты |

Дообучить одно направление переводчика, не трогая токенайзеры: `python train_translator_bpe.py --resume ru2en 20`. Сравнить оба направления по BLEU и chrF на 3000 отложенных парах: `python eval_translator.py`.

Общий код: `hf_data.py` (загрузка датасетов, токенизация как в сервере), `text_classifier.py` (BiLSTM для тональности и спама). Остальные файлы - учебные эксперименты: GPT с нуля (`mini_gpt.py`, `gpt_bpe.py`), GAN, первые версии задач с графиками.

Почему переводчик переобучен: прошлая версия выродилась. Декодер научился выдавать правдоподобные русские фразы и перестал смотреть на исходный текст. Сейчас pre-LN трансформер, разогрев learning rate, маски паддинга и ранняя остановка.
